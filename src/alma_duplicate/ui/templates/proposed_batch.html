Source-list example and coordinate conventions
name,ra,dec,redshift
B0218+357,02:21:05.47,+35:56:13.7,0.685
PKS1830-211,18:33:39.937,-21:03:39.80,0.886

ICRS RA must be at least 0° and below 360° (or below 24h). Dec can range from −90° to +90°. Sexagesimal minutes and seconds must each be below 60.

Redshift must be finite and greater than −1. Zero is valid. Negative values indicate a blueshift. Leave the value blank if it is unknown.

TXT uses the same header with spaces or tabs between fields. Quote names containing spaces. With a redshift column, use "" for a missing TXT value. Blank lines and full-line # comments are allowed.
